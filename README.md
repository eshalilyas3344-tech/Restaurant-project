# Bella Vista Restaurant Website

Bella Vista is a static, multi-page restaurant website built with HTML, CSS, and JavaScript. It is designed to present the restaurant in a polished, professional way while staying simple to maintain and easy to deploy.

## Project Goals

- Present the restaurant with a premium, modern visual style
- Keep navigation and page structure consistent across the site
- Make the content responsive and accessible on desktop and mobile
- Keep the codebase lightweight so updates are straightforward

## Features

- Responsive layout for desktop, tablet, and mobile devices
- Shared navigation and footer across all pages
- Menu category switching, gallery filtering, and form feedback
- Accessible skip link, focus states, and keyboard-friendly interactions

- [index.html](index.html): Homepage and entry point
- [menu.html](menu.html): Menu categories and pricing
- [reservations.html](reservations.html): Reservation form and booking details
- [gallery.html](gallery.html): Image gallery and lightbox interactions
- [about.html](about.html): Restaurant story and team information
- [contact.html](contact.html): Contact details and message form
- [restaurant-style.css](restaurant-style.css): Shared styling for every page
- [script.js](script.js): Shared interactive behavior

## Local Development

No build step is required.

1. Open the folder in VS Code or your file explorer.
2. Launch [index.html](index.html) in a browser.
3. Edit the HTML, CSS, or JavaScript files directly and refresh the page.

## Deployment

This project can be deployed to any static host, including GitHub Pages, Netlify, or Vercel.

### GitHub Pages

1. Push the repository to GitHub.
2. Open Settings > Pages.
3. Select Deploy from a branch.
4. Choose the main branch and the root folder.
5. Save the setting and wait for the site to publish.
